# Flaky Test Analyzer — Langflow AI Pipeline

Compares two Playwright JSON test runs and uses a Groq LLM to produce a structured QA report detecting flaky, consistent-failure, and retry-only-flaky tests.

After the Space boots, open the UI → add your Groq API key to the Groq node → Run.
