# Playwright API BDD Framework

This framework is a scalable Playwright API automation solution built in TypeScript using a BDD-style structure with Cucumber.

## Key Features
- Playwright API context for HTTP automation
- BDD feature file and step definitions
- Page manager with API page object pattern
- Environment configuration for `qa`, `dev`, and `prod`
- Centralized global config for base URL, timeout, and logging
- User credentials defined per environment
- JSON path mapping for booking and auth response fields
- Reusable utilities for payload generation and response extraction

## Folder structure
- `tests/features` - Cucumber feature files
- `tests/steps` - Step definitions
- `src/core` - Base test classes, global config, endpoints
- `src/pages/api` - API page objects
- `src/pages/pageManager.ts` - Central page manager
- `src/utils` - JSON path mapping, payload factories, response helper
- `src/data/environments` - Environment-specific configuration
- `src/data/users` - Environment-specific user credentials

## Setup
1. Install dependencies:
```bash
cd playwright-api-bdd-framework
npm install
```
2. Execute tests for a specific environment:
```bash
npm run test:qa
npm run test:dev
npm run test:prod
```

## Environment handling
- `NODE_ENV=qa` loads `src/data/environments/qa.json`
- `NODE_ENV=dev` loads `src/data/environments/dev.json`
- `NODE_ENV=prod` loads `src/data/environments/prod.json`

## Add new API pages
1. Create a new API page object under `src/pages/api`
2. Add it to `src/pages/pageManager.ts`
3. Call the page methods from step definitions

## Notes
- The BDD feature file uses environment configuration from the current `NODE_ENV`
- `ResponseHelper` uses JSON path mapping from `src/utils/jsonPath.ts`
- This framework is intentionally structured for extension with additional API endpoints, custom reporting, and CI/CD integration

## Reporting (Cucumber + Allure)

Where reports are generated and how to view them:

- Local HTML (Cucumber): `playwright-api-bdd-framework/reports/cucumber-<env>.html` (generated by the `report` script from the Cucumber JSON output).
- Allure results: `playwright-api-bdd-framework/allure-results` (generated by Allure adapter during test runs).
- Allure HTML report: `playwright-api-bdd-framework/reports/allure-report/index.html` (generated by `npm run allure:generate`).

CI behavior and artifacts:

- The GitHub Actions workflow runs tests and produces both Cucumber JSON and Allure results. The workflow uploads the `playwright-api-bdd-framework/reports` and `playwright-api-bdd-framework/allure-results` directories as an artifact named `api-test-reports` on each run.
- To download CI reports: open the workflow run in GitHub Actions, then download the `api-test-reports` artifact and extract the `reports/allure-report/index.html` or the Cucumber HTML file.

Java requirement (Allure)

- Generating the Allure HTML report locally requires a Java runtime available on your machine (Allure CLI depends on Java). Verify with:

```bash
java -version
```

- If you don't have Java installed or prefer not to install it locally, you can generate Allure reports using the Dockerized Allure CLI (no local Java required). Example:

```bash
# generate allure html using Docker (mount results and output)
docker run --rm \
	-v $(pwd)/allure-results:/app/allure-results \
	-v $(pwd)/reports:/app/reports \
	frankescobar/allure-docker-service:latest \
	allure generate /app/allure-results -o /app/reports/allure-report --clean

# then open the report
open reports/allure-report/index.html
```

Quick local run + view

```bash
cd playwright-api-bdd-framework
npm install
npm run test:qa          # runs Cucumber + Allure adapter, produces cucumber JSON + allure-results
npm run report           # generates the Cucumber HTML report (reports/cucumber-qa.html)
npm run allure:generate  # generates Allure HTML (requires Java) -> reports/allure-report
open reports/allure-report/index.html
```

Security note

- Do not commit secrets or production credentials into the repository. Use CI secrets or a secret manager for protected values.
